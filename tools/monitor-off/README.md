# 🖥️ 모니터 끄기 앱 (Windows)

노트북 **화면만** 끄는 작은 앱입니다. 컴퓨터는 계속 켜져 있어서
음악, 다운로드, 자동화 작업은 그대로 돌아갑니다.
마우스를 움직이거나 키보드를 누르면 화면이 다시 켜집니다.

## 설치 방법 (1분)

1. 이 폴더(`tools/monitor-off`)의 파일 2개를 내 컴퓨터로 받습니다.
   - `monitor-off.bat` (화면 끄기 프로그램)
   - `install.bat` (바탕화면 아이콘 만들기)
2. 두 파일을 **같은 폴더**에 둡니다. (예: `C:\내프로그램\`)
3. `install.bat` 을 더블클릭합니다.
4. 바탕화면에 **"모니터 끄기"** 아이콘이 생깁니다. 끝!

## 사용 방법

- 바탕화면의 **"모니터 끄기"** 아이콘을 더블클릭 → 약 0.5초 뒤 화면이 꺼집니다.
- 다시 켜려면 마우스를 움직이거나 아무 키나 누르세요.

## 자주 묻는 질문

- **"Windows의 PC 보호" 파란 창이 떠요** → `추가 정보` → `실행` 을 누르면 됩니다.
  (인터넷에서 받은 파일이라 한 번 확인하는 것입니다.)
- **파일 위치를 옮겼더니 아이콘이 안 돼요** → `install.bat` 을 다시 실행하세요.
